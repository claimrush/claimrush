# Voice and tone

Blend: Premium base (trust) + Competitive accent (speed).

## Always on (Premium base)
- Confident, precise, matter-of-fact
- Use clear nouns, avoid hype
- Prefer proof language: onchain, verifiable, transparent, security-reviewed (only if true)

## Accent layer (Competitive)
- Performance framing: compete, climb, outplay, optimize, dominance
- Make it feel fast without sounding reckless

## Words to use
- lock, stake, forge, furnace, Claim (mining claim), territory, rival, compete, dominance, crown, baron, strategy, onchain
- collect (for ETH payouts)
- harvest (for CLAIM token rewards from LP vault)

## Words to avoid
Avoid terms that imply a rewards-claiming tool.
- “airdrop claim”
- “claim rewards”
- “free claim”
- “get rich”
- “guaranteed”

## UI verbs (required)
Because “Claim” is both lore and the token ticker, UI CTAs MUST avoid using “Claim” as a verb.

Approved CTA verbs:
- ETH payouts: **Collect**
- LP rewards (CLAIM): **Harvest**
- Generic: **Withdraw** (only when the user is withdrawing funds they previously deposited)

## Writing style
- Short sentences
- Active voice
- No memes in official docs
