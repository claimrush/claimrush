# Positioning

## Tagline
**Lock Claims. Rule the Rush.**

## One-liner
**ClaimRush is an onchain strategy game with two loops: Takeover the Crown to mine CLAIM, or lock via the Furnace to earn takeover ETH royalties.**

Trust line (small):
- **0% platform fee.** Network gas and any third-party swap fees still apply.

## Naming rules
- Product name: **ClaimRush** (no space)
- Lore terms: **Claim**, **Furnace**, **King**, **Baron** are capitalized when used as in-world nouns.
- Token ticker: **CLAIM** (always uppercase, no space)
- Cashtag: **$CLAIM** — use only on social media (X, Farcaster) where the `$` prefix makes the ticker searchable/clickable. Do not use `$CLAIM` in UI strings, documentation, or technical writing. This follows the same convention as ETH, AAVE, UNI, MKR, and other major tokens.
- Compound tokens: **veCLAIM** (no `$`), **CLAIM/WETH** (trading pair, no `$`)

## UI wording rules (required)
To avoid confusion between:
- Claim (mining claim, lore)
- CLAIM (token)
- "claim rewards" (common DeFi verb)

The UI MUST NOT use "Claim" as a verb on buttons.

Approved verbs:
- ETH payouts: **Collect**
- LP rewards paid in CLAIM: **Harvest**
- Withdrawals: **Withdraw**

Examples:
- "Collect ETH"
- "Collect & Lock"
- "Harvest CLAIM"

## Clarifying note (user manual only)
Use this once in the user manual. Do not use on the homepage or other marketing pages.
- "Claim" refers to a **mining claim**, not claiming rewards.

## Usage rule
- "King-of-the-hill" is accurate. Mention it once in the user manual. Avoid using it in the one-liner or homepage hero.
