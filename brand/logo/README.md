# Logo usage

Default use: flat SVG in product and docs. Metallic renders are hero-only marketing art.

## Files
### Lockups
- `logo/svg/claimrush-lockup-color.svg`
  - Use on light backgrounds
- `logo/svg/claimrush-lockup-color-on-dark.svg`
  - Use on dark backgrounds (preferred for product UI)
- `logo/svg/claimrush-lockup-mono-white.svg`
  - Use on dark backgrounds
- `logo/svg/claimrush-lockup-mono-black.svg`
  - Use for 1-color print or emboss

### Icon
- `logo/svg/claimrush-icon-color.svg`
  - App icon, favicon, small placements
- `logo/svg/claimrush-icon-mono-white.svg`
  - Dark UI icon
- `logo/svg/claimrush-icon-mono-black.svg`
  - 1-color print

## Placement rules
- Clear space: keep at least 0.25x of the icon height around the mark.
- Minimum sizes
  - Icon: 24px minimum in UI
  - Lockup: 140px minimum width in web use
- Backgrounds
  - Prefer the **color-on-dark** lockup on `#0A0D14` and other dark surfaces.
  - Prefer the **mono-white** lockup when you need a 1-color mark.
  - Prefer the **color (dark text)** lockup on white or very light surfaces.

## Do not
- Substitute any other blue for the Base Blue (`#0000FF`) bar
- Add outlines or drop shadows to the logo SVG
- Stretch or skew
