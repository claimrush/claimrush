# ClaimRush Brand Kit

This folder publishes the public ClaimRush brand canon: identifiers, logo assets, color assets, icon rules, and writing rules that apply to public docs and references.

## Canonical identifiers
- Product name: **ClaimRush**
- Official domain: **claimru.sh**
- Token ticker: **CLAIM**
- Social cashtag: **$CLAIM** (social use only)
- User manual (online): <https://docs.claimru.sh/>
- Developer manuals: **docs/manuals/developer/** (also online at <https://developers.claimru.sh/>)
- X:
  - **@claimrushgame**
  - **@claimrushdev**

## Public brand canon
- `copy/voice.md` - baseline voice rules and verb policy
- `copy/tone-guide.md` - surface registers, anti-patterns, and reviewer checks
- `copy/positioning.md` - canonical tagline, one-liner, and naming rules
- `colors/palette.md` - palette reference
- `logo/README.md` - logo usage guidance

## Public asset directories
- `logo/` - SVG source, PNG exports, and favicons
- `colors/` - palette and token assets
